# Bruh Forever

A World of Warcraft addon. Bruh. Forever.

## Install

Download from [CurseForge](https://www.curseforge.com/wow/addons/bruh-forever), [WoWInterface](https://www.wowinterface.com) or [Wago](https://addons.wago.io), or grab the zip from the [latest GitHub release](../../releases/latest).

## Reporting bugs

Open an [issue](../../issues/new/choose) and fill in the template.

## Contributing

Fork, branch, open a pull request against `main`. All changes go through a PR.
